\chapter{Methodology}
This chapter details the methodology for the proposed Flow Planner framework, a novel hierarchical framework for long-horizon trajectory planning. This chapter is structured to build from foundational theory to the specific contributions of this work.

Section \ref{sec:cnf_formulation} first introduces the theoretical underpinnings of Conditional Flow Matching (CFM), a powerful, recently proposed paradigm for generative modeling. Building upon this, Section \ref{sec:planners} introduces a clever reformulation of the CFM objective, specializing this framework to the complex domains of robotic trajectory planning. This section goes over the general formulations for each planner component developed in this dissertation. Finally, Section \ref{sec:fp_framework} describes how these components are integrated into the complete hierarchical framework. 

The formulations presented herein are adapted from the convention from "An Introduction to Flow Matching and Diffusion Models" by MIT CSAIL \cite{holderriethIntroductionFlowMatching2025}, as well as the “Flow Matching Guide and Code” provided by Meta \cite{lipmanFlowMatchingGuide2024a}.


\section{Conditional Flow Matching Formulation}
\label{sec:cnf_formulation}
Recall in Section \ref{sec:fm_generative_models}, the general Flow Matching objective \ref{eq:fm_objective} is intractable because it requires access to the marginal probability path $p_t(x)$ and its corresponding vector field $u_t(x)$. Conditional Flow Matching (CFM) is a practical implementation that solves this problem by defining the probability path such that it yields a tractable target vector field. This transforms the objective into a stable and efficient regression problem. 

\subsection{CFM Training}
CFM constructs the path as a simple linear interpolation between a point sampled from a prior distribution $x_0 \sim p_0$ and a point from the data distribution $x_1 \sim p_1$. The prior is usually standard Gaussian noise $p_0(x) = \mathcal{N} (0, I)$. The point on the path at any time $t \in [0,1]$ is defined as:
\begin{equation}
	x_t=(1 - t)x_0+ tx_1.
\end{equation}
This specific construction is a type of Gaussian probability path referred to as the CondOT (Conditional Optimal Transport) path \cite{lipmanFlowMatchingGuide2024a}. The ground truth vector field requiring to move a particle along this straight path is constant at all times, and it is simply the vector connecting the two endpoints:
\begin{equation}
	u_t(x_t) = x_1-x_0.
\end{equation}
This replaces the intractable integral of the general formulation with a simple difference of two vectors, which are readily available during training.
By substituting this simplified target vector field into the general objective in \ref{eq:fm_objective}, one arrives at the final CFM loss function. The goal is to train a neural network $ v_{\theta} (x_t, t, c)$ to predict the target vector $(x_1 - x_0) $ given the interpolated point $x_t$ and time $t$, and any optional conditioning variables $c$. This objective is a straightforward L2 regression loss:
\begin{equation}
	L_{CFM}(\theta)=E_{t,p_0(x_0),p_1(x_1)}[\|v_\theta((1-t)x_0 + tx_1, t, c)-(x_1-x_0)\|^2].
\end{equation}
A single training step is summarized in Algorithm \ref{alg:cfm_training}


\begin{algorithm}
\caption{CFM Training}\label{alg:cfm_training}
\begin{algorithmic}[1]
\Require Dataset of samples $\mathbf{x}_1 \sim p_{\text{data}}$, neural network $v_\theta$, prior distribution $p_0$ (e.g.\ $\mathcal{N}(0, I)$)
\For{each training step}
    \State $\mathbf{x}_1 \sim p_{\text{data}}$ \Comment{Sample a data point}
    \State $\mathbf{x}_0 \sim p_{0}$ \Comment{Sample a noise vector}
    \State $t \sim \text{Unif}[0,1]$ \Comment{Sample a random time}
    \State $\mathbf{x}_t \gets (1-t)\mathbf{x}_0 + t\mathbf{x}_1$ \Comment{Compute interpolated point}
    \State $\mathbf{u} \gets \mathbf{x}_1 - \mathbf{x}_0$ \Comment{Compute target vector}
    \State $\mathcal{L}(\theta) \gets \|v_\theta(\mathbf{x}_t, t, c) - \mathbf{u}\|^2$ \Comment{Compute the loss}
    \State $\theta \gets \theta - \eta \nabla_\theta \mathcal{L}(\theta)$ \Comment{Gradient descent update}
\EndFor
\end{algorithmic}
\end{algorithm}
This is a simulation-free objective, hence it only requires sampling one data point, one noise vector, and a time to perform a standard regression update. It avoids the costly ODE solves of traditional CNF training and forms the foundational recipe for the specific planners detailed in the following sections. While the CondOT path is a common choice, the implementation in this dissertation utilizes a more general affine probability path. This formulation, known as the "Affine Conditional Flow Matching" variant in Albergo et al. [cite here], defines an exact conditional distribution over the interpolants instead of a single deterministic interpolation. This preserves key probabilistic properties, leading to more stable training dynamics and a closer theoretical alignment with Schrödinger Bridge formulations \cite{tongSimulationfreeSchrodingerBridges2024}. The detailed derivation of the base CFM objective is provided in Appendix \ref{app:cfm_derivation}.

\subsection{CFM Inference}
While the training process for CFM is simulation-free, inference requires simulating the learned dynamics. The goal of inference is to generate a new sample  $x_1$  that approximates a draw from the true distribution by solving an Ordinary Differential Equation (ODE). The trained neural network $v_\theta(x_t, t, c)$ now serves as an approximation of the true (but intractable) marginal vector field that transforms noise into data. Generation begins by sampling an initial point from the prior distribution $\mathbf{x}_0 \sim p_0(\mathbf{x})$. This point is then evolved from $t=0$ to $t=1$ by solving the following ODE:
\begin{equation}
	\frac{d\mathbf{x}t}{dt} \;=\; v_\theta(\mathbf{x}_t, t, c).
\end{equation}
The solution to this ODE, $x_1$, is the final generated sample. Since this ODE rarely has an analytical solution, it must be solved numerically. A common choice is the simple \textbf{Euler method}, detailed in Algorithm \ref{alg:euler}.
\begin{algorithm}
	\caption{Euler Method}\label{alg:euler}
	\begin{algorithmic}[1]
	\Require Neural network $v_\theta$, prior distribution $p_0$, condition $c$, number of steps $N$
	\State $\mathbf{x}_0 \sim p_0(\mathbf{x})$ \Comment{Sample an initial point}
	\State $\Delta t \gets 1/N$
		\For{$i = 0$ to $N-1$}
    		\State $t \gets i \cdot \Delta t$
		    \State $\mathbf{x}_{t+\Delta t} \gets \mathbf{x}_t + v_\theta(\mathbf{x}_t, t, c) \cdot \Delta t$ \Comment{Take a step along vector field}
		\EndFor
	\State \Return $\mathbf{x}_1$
\end{algorithmic}
\end{algorithm}

 It is worth noting that for Stochastic Differential Equations (SDEs), the corresponding simple solver is the Euler-Maruyama method. For the experiments in this dissertation, a more advanced solver, \textbf{the midpoint method} (a 2nd-order Runge-Kutta scheme) is employed \cite{lipmanFlowMatchingGuide2024a}. This choice offers a better trade-off between computational cost and numerical stability, leading to higher-quality samples compared to the basic Euler method.
